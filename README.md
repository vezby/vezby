# Hi, I'm Vezby

### Independent developer & creative director

I work on multiple game projects, combining creative direction, hands-on development and a lot of iteration. I enjoy turning an idea into an experience that feels clear, rewarding and fun to use.

My interests span **gameplay systems, UI/UX, progression, world interactions and the details that make an experience feel polished**.

---

### How I approach development

| Focus | My approach |
| :--- | :--- |
| **Creative direction** | Shape the concept, set priorities and connect individual features to a consistent player experience. |
| **Game development** | Build and refine gameplay loops, interactive systems and progression. |
| **Player experience** | Look for friction in tutorials, menus, controls and mobile layouts. |
| **Problem solving** | Investigate bugs, consider edge cases and verify changes before moving on. |
| **Iteration** | Playtest often, act on feedback and keep improving the details. |
